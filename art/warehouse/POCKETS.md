# Installations

Pitch-dark halls, each holding one lit set where robots live. The player rounds a corner in the dark and finds one. They are scattered at random through the warehouse, never grouped by kind, and never two of the same in sight of each other. Each set has a few things wrong with it (too big, too clean, facing the wrong way, leading nowhere).

Every set sits in darkness with no light spill between sets. The light belongs to the set: its own panels, lamps or glow. Robots linger inside, so it reads as their home.

Pieces are `art/warehouse/<name>` unless a group is given (`fun/vending_machine`). Mood shots for many of these are in `_moodshots/`, built by `moodshots.py`.
